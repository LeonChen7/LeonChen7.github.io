Put photo files here, then list them in `app/content/gallery.json`:

    { "src": "/photos/kyoto.jpg", "width": 1600, "height": 1067,
      "alt": "Lanterns at dusk in Kyoto",
      "title": "Lanterns", "meta": "Kyoto · 2027", "description": "A sentence or two about it." }

`alt` describes the picture for people who cannot see it. Resize to about
1600px on the long edge before adding so the page stays fast.
